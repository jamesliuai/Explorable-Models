Explorable Models is a toolkit for interactive explanations. A model supplies one committed frame to its diagrams, plots, equations, and values.

Start with a question

Open the composition studio and choose one of eight examples. Change an exact parameter, select a mark, or play an analytical model. Expand “Model, values and source document” to inspect the assumptions and editable JSON.

“Try a targeted revision” demonstrates a scripted styling edit that preserves the scientific run. It makes no AI request. Save document downloads a JSON artifact; Reopen restores a compatible artifact. Keep a downloaded copy for durable storage.

The experiment gallery retains rolling bodies, linear maps, base rates, Riemann sums, and an analytical oscillator, including its separate source-authoring and export workflow.

Embed an explanation

The matching @experiment-kit/core, @experiment-kit/player, and @experiment-kit/agent packages provide the runtime, React/plain-DOM surfaces, and authoring tools. These technical package names are retained from the project's original working name.

Use the matching tarballs supplied with the preview. npm availability and namespace ownership have not been established. React and ReactDOM are required for both surface APIs.

npm install ./experiment-kit-core-0.2.0-preview.1.tgz \
  ./experiment-kit-player-0.2.0-preview.1.tgz \
  ./experiment-kit-agent-0.2.0-preview.1.tgz react react-dom

The embedding guide covers worker configuration, lifecycle, CSP, React, and plain DOM. The source checkout also includes complete consumer examples.

Connect your agent

Register the provider-neutral visualization tools with your host. Agents can discover capabilities, create or revise a candidate document, inspect values, commit guarded changes, and save/reopen artifacts. Your application supplies the agent connection, authentication, and storage.

The local CLI also exposes stdio MCP. See the CLI/MCP guide and scoped relay example. Playback needs no account or AI connection.

A bounded developer preview

Supported: bounded analytical/parametric expressions, immutable numeric datasets, typed 2D geometry and plots, linked readouts, semantic edits, and portable JSON/SVG artifacts.

General 3D authoring, numerical solvers, stochastic adapters, arbitrary JavaScript, automatic unit conversion, automatic label layout, and full-page browser capture are outside this preview. The legacy gallery's rolling example has its own 3D renderer.

Examples remain scientifically unreviewed. Automated numerical, browser, and accessibility checks do not establish independent scientific review, accessibility certification, or learning efficacy. External agent/user trials, manual assistive-technology sessions, and real-device validation remain open.

Read the release evidence and limitations. Report a reproducible bug with a minimal public example and browser/package version. A private security-reporting destination must be established before publication; do not post sensitive details in public issues.

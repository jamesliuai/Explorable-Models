# Subject-review packets

Generated by `explorable-models activity review-packet --installed <templateId>` (see
[authoring.md §8](../authoring.md#8-review-packets)). Each packet is engineering evidence for a human subject reviewer:
exact digests, derivation, assumptions, limitations, conventions, reference cases with provenance and tolerances,
mutation sensitivity, boundary outcomes, stage-by-stage captures, task intent and accessible alternatives. None is a
review. Every reviewer sign-off section is empty; an engineering agent cannot sign it, and the catalogue status of
these templates stays `reference-checked` until a host-trusted review record names their exact digests.

The unified release tarball ships each packet's README, packet.json, SVG captures and companion text, but not the PNG
card captures (about 8 MB), which stay in the repository; regenerate them with the command below.

The two spatial templates are captured through the learner surface's 2D projection fallback: the capture page does not
load a spatial renderer yet, and the same command will add 3D views once it does. Regenerate all packets from the
repository root after any change to a template, model, kernel, reference suite or the learner surface:

```sh
for id in quadratic-gradient-descent function-derivative linear-transformation vector-orientation-3d quadratic-surface-gradient; do
  npm run models -- activity review-packet --installed "$id" --out "docs/study-harness/review-packets/$id" --index 4
done
```
